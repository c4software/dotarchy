# Hyprland Keybindings

Guide complet des raccourcis clavier pour Hyprland.

> [!NOTE]
> `SUPER` fait référence à la touche Super/Windows

## Presse-papiers

| Raccourci | Action |
|-----------|--------|
| `SUPER+C` | Copier |
| `SUPER+V` | Coller |
| `SUPER+X` | Couper |

## Multimédia

### Contrôles de base

| Raccourci | Action |
|-----------|--------|
| `XF86AudioRaiseVolume` | Augmenter le volume |
| `XF86AudioLowerVolume` | Diminuer le volume |
| `XF86AudioMute` | Activer/désactiver le son |
| `XF86AudioMicMute` | Activer/désactiver le microphone |
| `XF86MonBrightnessUp` | Augmenter la luminosité |
| `XF86MonBrightnessDown` | Diminuer la luminosité |

### Ajustements précis (1%)

| Raccourci | Action |
|-----------|--------|
| `ALT+XF86AudioRaiseVolume` | Volume +1% |
| `ALT+XF86AudioLowerVolume` | Volume -1% |
| `ALT+XF86MonBrightnessUp` | Luminosité +1% |
| `ALT+XF86MonBrightnessDown` | Luminosité -1% |

### Lecture média

| Raccourci | Action |
|-----------|--------|
| `XF86AudioNext` | Piste suivante |
| `XF86AudioPrev` | Piste précédente |
| `XF86AudioPlay` | Lecture/Pause |
| `XF86AudioPause` | Pause |

|-----------|--------|
| `SUPER+Shift+Left` | Échanger fenêtre vers la gauche |

### Cycle entre fenêtres

| Raccourci | Action |
|-----------|--------|
| `ALT+Tab` | Fenêtre suivante dans le workspace |
| `ALT+Shift+Tab` | Fenêtre précédente dans le workspace |
| `SUPER+Tab` | Rechercher des applications (toutes fenêtres) |

### Redimensionner

| Raccourci | Action |
|-----------|--------|
| `SUPER+-` | Étendre la fenêtre vers la gauche |
| `SUPER+=` | Rétrécir la fenêtre vers la gauche |
| `SUPER+Shift+-` | Rétrécir la fenêtre vers le haut |
| `SUPER+Shift+=` | Étendre la fenêtre vers le bas |
| `ALT+Left` | Étendre la fenêtre vers la gauche |
| `ALT+Right` | Rétrécir la fenêtre vers la gauche |
| `ALT+Up` | Rétrécir la fenêtre vers le haut |
| `ALT+Down` | Étendre la fenêtre vers le bas |

### Navigation par molette

| Raccourci | Action |
|-----------|--------|
| `SUPER+Mouse wheel down` | Workspace suivant |
| `SUPER+Mouse wheel up` | Workspace précédent |

### Souris

| Raccourci | Action |
|-----------|--------|
| `SUPER+Left click` | Déplacer la fenêtre |
| `SUPER+Right click` | Redimensionner la fenêtre |

### Multi-moniteurs

| Raccourci | Action |
|-----------|--------|
| `SUPER+Shift+ALT+Left` | Déplacer workspace vers moniteur gauche |
| `SUPER+Shift+ALT+Right` | Déplacer workspace vers moniteur droit |

| `ALT+3` | Aller à la fenêtre 3 du groupe |

|-----------|--------|

| Raccourci | Action |
|-----------|--------|
| `SUPER+,` | Rejeter la dernière notification |
| `SUPER+Shift+,` | Rejeter toutes les notifications |
| `SUPER+Ctrl+,` | Basculer le mode Ne pas déranger |

## Utilitaires

| Raccourci | Action |
|-----------|--------|
| `SUPER+Ctrl+I` | Basculer le verrouillage automatique |
| `Print` | Menu de capture d'écran |
| `ALT+Shift+4` | Menu de capture |
| `SUPER+Print` | Sélecteur de couleur |

## Notes

- Tous les raccourcis multimédia fonctionnent même lorsque l'écran est verrouillé
- Les ajustements de volume et luminosité utilisent `swayosd-client` pour l'affichage OSD
- Les fenêtres en plein écran ont une couleur de bordure différente
