# Niri Keybindings

Guide complet des raccourcis clavier pour Niri (configuration bépo).

> [!NOTE] > `Mod` fait référence à la touche Super/Windows

## Presse-papiers

| Raccourci | Action |
| --------- | ------ |
| `Mod+C`   | Copier |
| `Mod+V`   | Coller |
| `Mod+X`   | Couper |

## Multimédia

### Contrôles de base

| Raccourci               | Action                           |
| ----------------------- | -------------------------------- |
| `XF86AudioRaiseVolume`  | Augmenter le volume              |
| `XF86AudioLowerVolume`  | Diminuer le volume               |
| `XF86AudioMute`         | Activer/désactiver le son        |
| `XF86AudioMicMute`      | Activer/désactiver le microphone |
| `XF86MonBrightnessUp`   | Augmenter la luminosité          |
| `XF86MonBrightnessDown` | Diminuer la luminosité           |

### Ajustements précis (1%)

| Raccourci                   | Action         |
| --------------------------- | -------------- |
| `Alt+XF86AudioRaiseVolume`  | Volume +1%     |
| `Alt+XF86AudioLowerVolume`  | Volume -1%     |
| `Alt+XF86MonBrightnessUp`   | Luminosité +1% |
| `Alt+XF86MonBrightnessDown` | Luminosité -1% |

### Lecture média

| Raccourci        | Action           |
| ---------------- | ---------------- |
| `XF86AudioNext`  | Piste suivante   |
| `XF86AudioPrev`  | Piste précédente |
| `XF86AudioPlay`  | Lecture/Pause    |
| `XF86AudioPause` | Pause            |

## Gestion des fenêtres (Tiling)

### Fenêtres de base

| Raccourci | Action                          |
| --------- | ------------------------------- |
| `Mod+W`   | Fermer la fenêtre               |
| `F11`     | Maximiser la colonne            |
| `Mod+F11` | Basculer en plein écran fenêtré |
| `Mod+P`   | Centrer la colonne              |
| `Mod+S`   | Basculer le mode flottant       |

### Maximisation et expansion

| Raccourci       | Action                          |
| --------------- | ------------------------------- |
| `Mod+Alt+Up`    | Maximiser la colonne            |
| `Mod+Alt+Down`  | Restaurer la colonne            |
| `Mod+Alt+Left`  | Étendre à la largeur disponible |
| `Mod+Alt+Right` | Étendre à la largeur disponible |

### Navigation

| Raccourci   | Action                     |
| ----------- | -------------------------- |
| `Mod+Left`  | Focus colonne gauche       |
| `Mod+Right` | Focus colonne droite       |
| `Mod+Up`    | Focus workspace au-dessus  |
| `Mod+Down`  | Focus workspace en-dessous |
| `Mod+Tab`   | Basculer en mode aperçu    |

### Espaces de travail (bépo)

| Raccourci | Action      |
| --------- | ----------- |
| `Mod+"`   | Workspace 1 |
| `Mod+<`   | Workspace 2 |
| `Mod+>`   | Workspace 3 |
| `Mod+(`   | Workspace 4 |
| `Mod+)`   | Workspace 5 |
| `Mod+@`   | Workspace 6 |
| `Mod++`   | Workspace 7 |

### Déplacer vers un workspace

| Raccourci    | Action                    |
| ------------ | ------------------------- |
| `Mod+Ctrl+"` | Déplacer vers workspace 1 |
| `Mod+Ctrl+<` | Déplacer vers workspace 2 |
| `Mod+Ctrl+>` | Déplacer vers workspace 3 |
| `Mod+Ctrl+(` | Déplacer vers workspace 4 |
| `Mod+Ctrl+)` | Déplacer vers workspace 5 |
| `Mod+Ctrl+@` | Déplacer vers workspace 6 |
| `Mod+Ctrl++` | Déplacer vers workspace 7 |

### Déplacer les fenêtres

| Raccourci         | Action                           |
| ----------------- | -------------------------------- |
| `Mod+Shift+Left`  | Déplacer la colonne à gauche     |
| `Mod+Shift+Right` | Déplacer la colonne à droite     |
| `Mod+Shift+Up`    | Déplacer la fenêtre vers le haut |
| `Mod+Shift+Down`  | Déplacer la fenêtre vers le bas  |

### Redimensionner

| Raccourci   | Action                      |
| ----------- | --------------------------- |
| `Alt+Left`  | Réduire la largeur (-10%)   |
| `Alt+Right` | Augmenter la largeur (+10%) |
| `Alt+Up`    | Réduire la hauteur (-10%)   |
| `Alt+Down`  | Augmenter la hauteur (+10%) |

### Navigation par molette

| Raccourci             | Action              |
| --------------------- | ------------------- |
| `Mod+WheelScrollDown` | Workspace suivant   |
| `Mod+WheelScrollUp`   | Workspace précédent |

### Multi-moniteurs

| Raccourci             | Action                                  |
| --------------------- | --------------------------------------- |
| `Mod+Shift+Alt+Left`  | Déplacer workspace vers moniteur gauche |
| `Mod+Shift+Alt+Right` | Déplacer workspace vers moniteur droit  |

### Groupement de fenêtres

| Raccourci | Action                                   |
| --------- | ---------------------------------------- |
| `Mod+G`   | Grouper/Dégrouper en affichage à onglets |
| `Mod+Q`   | Consommer la fenêtre dans le groupe      |
| `Mod+H`   | Expulser la fenêtre du groupe            |

## Notes

- Tous les raccourcis multimédia fonctionnent même lorsque l'écran est verrouillé (`allow-when-locked=true`)
- Les ajustements de volume et luminosité utilisent `swayosd-client` pour l'affichage OSD
- La configuration est optimisée pour le layout clavier **bépo**
- Les raccourcis de workspace utilisent les touches bépo : `" < > ( ) @ +`
